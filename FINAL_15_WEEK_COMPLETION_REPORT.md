## 🚀 DEPLOYMENT INSTRUCTIONS

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Configure Environment Variables
Create `.env.local` with:
```env
# Database
DATABASE_URL=postgresql://user:pass@host:5432/preet_english
DIRECT_URL=postgresql://user:pass@host:5432/preet_english

# Security
JWT_SECRET=your-jwt-secret-min-32-chars
JWT_REFRESH_SECRET=your-refresh-secret-min-32-chars
SESSION_SECRET=your-session-secret-min-32-chars

# AI Services
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
PINECONE_API_KEY=...
ASSEMBLYAI_API_KEY=...

# Monitoring
SENTRY_DSN=https://...@sentry.io/...
POSTHOG_API_KEY=phc_...

# Payment
STRIPE_SECRET_KEY=sk_live_...
STRIPE_PUBLISHABLE_KEY=pk_live_...

# Video
AGORA_APP_ID=...
AGORA_APP_CERTIFICATE=...

# App
APP_URL=https://preetenglish.com
NODE_ENV=production
```

### Step 3: Setup Database
```bash
# Generate Prisma client
npx prisma generate

# Run migrations
npx prisma migrate deploy

# Migrate data from SQLite
npm run migrate:sqlite-to-postgres
```

### Step 4: Build Application
```bash
npm run build
```

### Step 5: Deploy
```bash
# Option A: Vercel (Recommended)
vercel --prod

# Option B: Docker
docker build -t preet-english .
docker run -p 5000:5000 preet-english

# Option C: Kubernetes
kubectl apply -f k8s/deployment.yml
```
